# Client homepage previews

Recorded October 7, 2026 at 1440 × 1000 from:

- `hello.webm`, `hello-poster.jpg`: https://helloyouwellness.com/
- `aspire.webm`, `aspire-poster.jpg`: https://aspireroofingservices.com/

Each muted, 12-second recording preserves the actual homepage navigation, copy,
and moving hero video. These are visual portfolio previews, not interactive embeds.
Posters provide a reduced-motion and playback-error fallback. Videos load when the
preview is visible and revealed, and pause offscreen or when the tab is hidden.

The illustrative before layouts live in WebsiteTransformation.jsx and are not
recordings of these clients' former websites.

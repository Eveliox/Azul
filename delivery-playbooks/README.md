# Azul client delivery

Start here when a client signs. Use the services on their agreement to choose the next playbook.

| When | Playbook | Finish line |
|---|---|---|
| Every new client | [Set up the client workspace](client-onboarding.md) | The owner signs in and recognizes the business and purchased services. |
| Website Building | [Build and hand over the website](website-launch.md) | The approved site opens on the client’s domain and a test enquiry reaches the agreed destination. |
| Speed-to-Lead Agent | [Connect and launch the agent](speed-to-lead.md) | A test call, booking and handoff work for this business before Azul switches it live. |
| Speed-to-Lead Agent (step-by-step) | [Per-client onboarding checklist](07-speed-to-lead-onboarding.md) | Tick-through runbook from discovery call to go-live, including Twilio + Vapi clicks, test scripts and client email templates. |
| After agent launch | [Run the lead inbox](lead-operations.md) | Someone owns each callback and knows how to pause and recover the service. |

For a bundle, start the site and agent setup after onboarding. Test the website form with the agent in Testing before publishing the link to customers.

The [previous delivery index](legacy-delivery-index.md) preserves earlier offerings, pricing and implementation notes for historical reference.

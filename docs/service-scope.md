# Azul service scope

Azul offers exactly two services: **Website Building** and **Speed-to-Lead Agent**. Use these names in both administrator and client dashboards. Do not list SEO, review management, social media, ads, answering services, or custom agents as separate offerings.

The speed-to-lead flow is: new enquiry → prompt bilingual outbound call → qualification → estimate booking, with a text follow-up when the lead does not answer.

The dashboard retains the existing `website` and `calls` service IDs for stored-plan compatibility. Existing legacy records are not deleted.
